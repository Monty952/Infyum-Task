# WhatsApp Message Recovery & Chat Backup

A simple Android application built as a practical Android development task. The app captures WhatsApp notifications using Android's NotificationListenerService, stores the available notification data locally, and provides chat backup and restore functionality.

## Features

### 1. WhatsApp Deleted Message Recovery
- Captures WhatsApp notifications using `NotificationListenerService`
- Displays captured messages inside the application
- Shows sender name
- Shows message/notification preview
- Shows date and time
- Identifies the available message type
- Search and filtering of captured messages
- Stores captured data locally

### 2. Chat Backup
- Stores captured messages using Room Database
- Displays saved chats and messages
- Creates a local backup
- Restores previously created backups
- Data remains available after restarting the application

## How It Works
1. The user grants Notification Access permission to the application.
2. The application listens for notifications generated by WhatsApp.
3. Available notification information is extracted from the notification.
4. The captured information is stored locally using Room Database.
5. The user can view, search, and filter the saved messages.
6. The user can create a backup of the locally stored data.
7. Backup data can be restored when required.

## Permissions
The application requires the user to manually enable Notification Access in Android settings.
The application only processes notification information made available through Android's notification system.

## Media Limitations
The application does not use private, unofficial, or unsupported WhatsApp APIs.
Access to photos, videos, documents, voice notes, video notes, GIFs, and stickers depends on what information and data Android/WhatsApp expose through the notification.
If a particular media item cannot be accessed through the notification system, the application does not generate fake media data. It displays only the information that is legitimately available.

## Privacy
Captured notification data is stored locally on the device.
The application does not access WhatsApp's private database or use unsupported WhatsApp APIs.

## Project Setup

### Requirements
- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration (JDK 17)
- Android device or emulator

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Monty952/Infyum-Task.git
   ```
2. Open the project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Connect an Android device or start an emulator.
5. Run the application.
6. Open Android settings and enable Notification Access for the application.
7. Send or receive WhatsApp notifications and check the application for captured notification data.
